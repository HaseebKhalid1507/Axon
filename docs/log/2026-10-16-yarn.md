## What changed
- `src/rope.rs` (new): `Yarn` (llama.cpp's corr dims, ramp, mscale), `RopeArgs` (`--rope-scaling yarn|none`,
  `--rope-scale`, `--yarn-orig-ctx`, `--yarn-beta-fast/slow`, `--yarn-attn-factor`) written into the model's
  metadata as GGUF `rope.scaling.*` keys before `check_supported`; `context_length` becomes orig x factor.
- `model.rs`: `rope_freqs` applies YaRN after Llama 3's factors; `check_supported` accepts yarn (factor > 1,
  not gemma3), still refuses unknown types; CPU table times `rope_m` (f64 multiply before the f32 rounding).
  `freqs` is a `Box<[f64]>` to stay under clippy's large_enum_variant bound with the new field.
- `decode.cu` `rope_table`, `prefill.cu` `rope_table_b`: a trailing `float m` (1.0 = the old bits); the q8
  cache's key shift `ksh` is scaled by it too.
- gen / logits / chat / serve take the flags. Off by default; default outputs byte-identical.
