# 2026-11-12: `axon pull` (dist track)

**What:** `axon pull NAME | OWNER/REPO/FILE.gguf` downloads a GGUF from Hugging Face into the models directory
(`$AXON_MODELS_DIR`, else `$XDG_DATA_HOME/axon/models`, else `~/.local/share/axon/models`; `OWNER/REPO/FILE` under
it). Twelve names (`pull::ALIASES`, `axon pull --list`) pin a file at a commit with its SHA-256; any other file is
checked against the SHA-256 Hugging Face publishes (`x-linked-etag`, the LFS oid) and fetched at the commit that
reported it. `gen`, `chat`, `serve`, `info` and `--draft-model` take a name, an `OWNER/REPO/FILE.gguf` or a pulled
file's name where they took a path.

**How:** `curl` does the HTTPS (axon has no TLS stack; curl ships with Linux and Windows 10+), HTTPS-only on
redirects too, `HF_TOKEN` on its stdin. The bytes stream into axon, are hashed in-crate (`src/sha256.rs`, FIPS
180-4, NIST vectors; no dependency on `sha256sum`/`certutil` and their output formats, and the hash is done in the
same pass as the write) and appended to `FILE.part`, resumed after an interruption (the `.part` hashed again
first), renamed into place only when size and SHA-256 match. A mismatch deletes the `.part`.

**Untrusted input:** owner, repo and each path component must be one `[A-Za-z0-9._-]` component starting with a
letter or digit; hostile specs (traversal, absolute, separators, `%2e`, options, non-ASCII, NUL) and a 50k-string
fuzz never leave the models directory. Response headers are validated (64-hex checksum, 40-hex commit, size).

**Review (shady, 7/10, 11-13):** (1) `axon serve qwen2.5-0.5b` called the model `qwen2.5-0.5b-instruct-q4_k_m`,
so a client sending the name it was told got a 404: the name `axon pull` resolved is now the model id
(`Opts::name`), the banner shows the file, a path keeps its stem (`serve_pulled_name_is_the_model_id`). (2) curl
read `~/.curlrc` (its `insecure`, `location-trusted` or `trace` would have undone the HTTPS and token rules): `-q`
is now its first argument (`pull_curl_ignores_curlrc`). Also: a file keeps its repo directories under the models
directory (two `m.gguf` in one repo no longer collide); `FILE.part.want` names the download a `.part` belongs to,
and a `.part` of another version starts over; the `.part` is renamed with its lock held, and a pull that finds it
renamed away by another stops; `HF_TOKEN` needs curl 7.58+. The untested names ran on a 4090 before the regate
(PR body).
