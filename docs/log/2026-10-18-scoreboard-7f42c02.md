# RunPod GPU scoreboard re-run on main 7f42c02 (docs only)

- Date: 2026-10-18. Branch: docs/scoreboard-7f42c02. Base: main 7f42c02 (#83). Status: open.
- Why: the README and docs/benchmarks-gpu.md quoted the 10-15 RunPod board (main f8d8a86, llama.cpp 4413a19,
  ollama 0.35.0). Main has merged 60 PRs since (`git log --first-parent f8d8a86..7f42c02`), including #33 (Hopper wgmma) and #30 (r5 decode), and
  llama.cpp and ollama have both moved. The board was re-run on 10-18 on the same three GPUs.

## What changed
- `README.md`: the RunPod paragraph and table now give the 10-18 board (main 7f42c02, llama.cpp master ff5a233,
  ollama 0.40.6). The "H100 prefill trails the 4090" paragraph is rewritten: on this board the H100 leads the
  4090 on 7B / 8B pp2100 but still trails it on 0.5B–3B pp2100 and on every pp560 cell.
- `docs/benchmarks-gpu.md`: new current section with method, hardware (from each pod's hw.txt), full per-GPU
  tables, a "what changed since 10-15" table and this board's caveats. The 10-15 section is kept as it was under
  a "Previous board" heading.
- `docs/results.md`: a dated entry for the board, with its cost and the new pods-never-compile rule; the
  "none of the boards was run on 4507c75" banner gets an exception line for this board.

## Sources and method
- case's report `sb-runpod-7f42c02.md` (overnight workspace) and the raw logs
  `~/.cache/axon-pods/sb/results-7f42c02/{h100sxm,rtx5090,rtx4090}/{sb.log,sb-axl.log,sb-oll.log,hw.txt}`
  (the 5090 has only sb.log, which holds both passes), plus gpumon.csv / loadavg.log for the observed-load
  columns. Old board: `~/.cache/axon-pods/sb/results/<gpu>/sb.log`, and `sb-ollama.log` for the 4090/5090 ollama
  columns (the 10-15 docs used that re-run too).
- Every median was parsed from the logs by a script, which also checked each logged median against the median
  of its three raw samples. Ratios and deltas are computed from the unrounded medians, then rounded to 2
  decimals (ratios) or 0.1 % (deltas). The tables match case's report cell for cell.
